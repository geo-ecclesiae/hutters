Spatial-historical database of Budziarze settlements in the Zamoyski Estate and the Solska Forest, developed for a doctoral dissertation on forest settlement and human–environment relations in the 18th and 19th centuries.
The database combines written and cartographic sources and records source manifestations for five identification criteria: inhabitants, name, settlement type, location, and part–whole relations. The osady_synteza table contains the synthetic identification and classification of settlement units, including confidence status, morphology, function, genesis, and post-regulation fate.
The database is stored as a GeoPackage and uses EPSG:2180.Important: The database contains both confirmed/probable settlements used in the main analyses and possible candidates retained for documentation and further verification. For analytical purposes, users should normally filter osady_synteza.status_id to pewny (“certain”) and prawdopodobny (“probable”).
